tic-tac-toe-c
Classic Tic-Tac-Toe program developed in C language.

Basically, it's a tic-tac-toe game where we use matrix addresses to place X or O. Very good for those who want to practice matrices and play with friends.

🎮 How to Play / Como Jogar
The game is played on a 3x3 grid (matrix).
Players take turns choosing a row and a column (from 1 to 3) to place their mark (X or O).
The first player to get 3 of their marks in a row (up, down, across, or diagonally) is the winner.
If all 9 squares are full and no player has 3 marks in a row, the game ends in a tie (draw).
